=============================================

A live demo on four Compose Multiplatform screens, with no slides. It answers the brief's judging points (challenges/jetbrains-kmp.md):
- two or more platforms;
- a native-feeling UX;
- what's shared in commonMain, plus the backend, localization and shared AI;
- innovation;
- the agentic process;
- the presentation.

The setup details and fallbacks are in jetbrains-demo-notes.md and jetbrains-live.md. This file is the run of the show, line by line. Rebuilt on 22 Nov, 11:00, against main at 7f29d88.

DON'T CLAIM
-----------

- That Koog works offline, on the phone, or in the browser. It runs on the server JVM and calls the model over the network at every step. Its wasm target only compiles.
- That the passenger chat is the Koog agent. The chat is a separate model call (Claude Sonnet 5.5 with the journey planner); Koog is the admin's draft.
- That the phone answers offline. Live, a phone without a connection now says "Sorry, I couldn't get an answer just now" (83b02af). The rules engine on the phone only answers in the scripted, serverless mode.
- That the dashboard shows the agent's tools. It did until 41f6c57; now only the optional log window does.
- iOS. "One more target and three actual functions; no Xcode on our laptops."
- That nextMove() runs on the phone. The server computes it.
- That the Bluetooth beacon on stage is real. It's simulated; the scanning code is real.

IF SOMETHING BREAKS
-------------------

The fallbacks are in jetbrains-demo-notes.md. In short:
- If Koog fails or takes over 60 s, the server falls back to the single-call draft on its own; the dialog looks the same. Speak the Koog point anyway.
- If the AI fails entirely, a standard template fills the boxes. OPERATOR publishes that; PRESENTER: "And if the AI is down, the control room still has a template."
- If the chat answers "Sorry…", PHONE asks again once. If it fails again, skip to the dashboard's Passenger questions: the question is still grouped there.
- If a screen is dead, point at its twin.
- If the demo is dead, BACKUP plays the recording.
